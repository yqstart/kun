# kun 多平台发布

## 触发方式

推送 `v*` 标签（如 `v0.1.0`）自动触发发布，也可在 Actions 页手动 **Run workflow**：

```bash
git tag v0.1.0
git push origin v0.1.0
```

## 产物

| 平台 | 产物 | 构建方式 |
|---|---|---|
| macOS Apple Silicon | `kun-<版本>-macos.dmg` | macos-latest（原生 ARM） |
| macOS Intel | `kun-<版本>-macos.dmg` | macos-15-intel（官方 Intel runner） |
| Linux x64 | `kun-<版本>-linux-x64.tar.gz` | ubuntu-22.04 |
| Windows x64 | `kun-<版本>-windows-x64.zip` | windows-latest |

- 版本号取自 tag（`v0.1.0` → `0.1.0`）
- Release 正文从 `CHANGELOG.md` 提取对应版本段落
- 若 tag 已存在同名 Release（如手动创建），产物自动挂载；否则自动创建

## 本地预览打包（macOS）

```bash
cargo build --release
./scripts/package-macos.sh 0.1.0
# 产出 target/release/kun-0.1.0-macos.dmg 与 kun.app
```

打包脚本逻辑：生成图标（`make-icon.swift`，渐变紫 + K 字母）→ 组装 .app bundle（Info.plist）→ `hdiutil` 制作 dmg。

## macOS 安装后提示「已损坏」

未签名 / 未公证导致。解除隔离：

```bash
xattr -cr "/Applications/kun.app"
```

然后右键 → **打开**。

## Windows SmartScreen 提示「已保护你的电脑」

下载 zip 后若 SmartScreen 拦截，点 **更多信息** → **仍要运行**；或在 PowerShell 解除下载标记：

```powershell
Unblock-File -LiteralPath "$env:USERPROFILE\Downloads\kun-*.zip"
```

要彻底消除提示，需配置 Windows 代码签名证书（在仓库 Secrets 配置 `WINDOWS_CERTIFICATE` 系列后启用签名步骤）。

## 维护者侧说明

- 工作流文件：`.github/workflows/release.yml`（发布）、`ci.yml`（push/PR 检查）
- 网络集成测试在 CI 上自动跳过（检测不到测试 sshd）；本地跑集成测试需先 `./scripts/test-sshd.sh start`
- 发布前建议本地过一遍：`cargo test --workspace && cargo clippy --workspace --all-targets -- -D warnings && cargo fmt --all --check`
