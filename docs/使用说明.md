# kun 使用说明

## 快速上手

1. 启动 kun：`cargo run`（或从 Release 安装）
2. **本地终端**：启动即进入本地 shell，直接使用
3. **连接远程主机**：按 `⌘N`，或打开标签栏「⚙ 设置」→「主机管理」→「新建连接」，填写主机 / 端口 / 用户名 / 认证方式
4. 连接成功后：中央为远程终端，点击右上角 **SFTP** 按钮展开面板（可拖拽调整宽度）

## 快捷键

| 快捷键 | 功能 |
|---|---|
| ⌘N | 新建连接 |
| ⌘T | 新建本地终端 |
| ⌘W | 关闭当前标签 |
| ⌘1 - ⌘9 | 切换标签 |
| ⌘, | 打开/关闭设置 |
| ⌥1 - ⌥3 | 切换主题（深色 / 深蓝 / 霓虹） |

## 检查更新

- 启动后自动在后台检查 GitHub Releases 新版本
- 「设置」→「关于」→「检查更新」可手动触发；状态提示：新版本可用 / 已是最新 / 检查失败
- 发现新版后弹窗显示版本与更新说明，点击「下载并安装」即在应用内下载（进度条）并自动安装、重启

## 主机管理

- 配置持久化于 `~/.config/kun/hosts.toml`（TOML 格式，可手编）
- **单击**条目选中（左侧出现紫色指示条），**双击**直接连接
- 主机行单击选中、双击连接；行尾删除按钮移除主机。标签栏 `>_` 快捷入口中单击主机即可连接

## 远程终端

- 支持密码 / 私钥认证（私钥可带口令）
- 远程 shell 与本地终端行为一致：彩色输出、滚动（滚轮）、粘贴（⌘V，括号粘贴自动识别）

## SFTP 面板

| 操作 | 方式 |
|---|---|
| 进入目录 | 单击目录选中，再次单击进入（`目录名/` 显示） |
| 返回上级 | 点击列表首行 `..`，或在列表空白处右键选择「打开上级目录」 |
| 上传 / 新建目录 / 刷新 | 在列表行或空白处右键选择对应操作 |
| 下载 / 重命名 / 删除 | 选中条目后右键选择对应操作（删除有确认对话框） |
| 定位终端目录 | `⌘⇧L`，或右键选择「定位到当前终端目录」 |
| 传输进度 | 面板底部进度条（进行中 / 完成 / 失败） |

## 主题

- 「设置」→「外观」切换三套主题，每套包含独立终端调色板
- 快捷键 ⌥1-⌥3 快速切换

## 常见问题

### 回车不执行命令

多为中文输入法（IME）激活时回车被输入法消费（用于确认拼音候选）。切换英文输入法（`⌃Space` 或 `CapsLock`）后再回车即可——所有终端应用的共性行为。

### macOS 提示「已损坏，无法打开」

产物未签名所致，执行 `xattr -cr "/Applications/kun.app"` 后重新打开。

### 终端字体 / 中文显示

自动加载系统 SF Mono 与中文字体（PingFang / STHeiti），无需配置。
